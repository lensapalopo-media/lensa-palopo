Cloud Database Resmi

Koneksi Supabase Cloud Database

Hubungkan ke project Supabase gratis Anda agar seluruh foto, berita, video, dan pengaturan tampilan tersimpan di Cloud dan sinkron di semua perangkat pengunjung Vercel.

Status: Terhubung Otomatis ke Supabase Cloud (twmgcozbtptkesemxpth.supabase.co)

Hosting Vercel & Cadangan Berkas (data/photos.json)

Project ini sudah dilengkapi konfigurasi vercel.json. Saat di-hosting di Vercel:
1. Jika Supabase Cloud terhubung, setiap perubahan yang Anda simpan di Admin langsung tampil secara real-time di semua pengunjung tanpa perlu deploy ulang.
2. Anda juga dapat mengunduh berkas photos.json (berisi seluruh paket foto, berita, video, wisata, dan tampilan) untuk disimpan ke folder data/photos.json di repositori GitHub/Vercel Anda.
